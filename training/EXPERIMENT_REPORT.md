## 정확히 말할 수 있는 것

> "마음결의 Qwen2.5 1.5B 모델에 대해 CPU를 사용한 소규모 LoRA 실험 학습 6스텝을 완료했고, 가중치와 학습·검증 손실을 확인했다."

**말할 수 없는 것:** 전문 상담 데이터 전체 학습 완료, 상담 능력 향상 확정, 의료·심리 임상 검증 완료, 서비스에 학습 모델 자동 적용 완료.

현재 6스텝은 기능 확인 목적의 **시험 학습**입니다. 모델의 대화 능력 개선이나 자살·자해 대응의 신뢰성을 입증하지 않습니다. KMI는 실제 내담자-전문가 상담 녹음이 아니며, 연구진이 전문성을 반영하여 제작하고 평가한 합성 대화입니다.

## 실제 모델 품질 비교

- 별도 검증 실행: https://github.com/minjunmon109/maumgyeol-ai/actions/runs/40973257436
- 실제 기본 모델과 6스텝 LoRA 모델의 **생성 답변**을 같은 위기 대응 사례에 적용하고 비교하는 자동 검사입니다.
- 이 검사 결과는 참고용이며, 임상가가 직접 사례별로 평가한 시험은 아닙니다.
- `model-release.json`은 `active: false`로 유지합니다. 학습 결과를 일반 사용자 사이트에 배포하지 않습니다.

## 추후 배포 판정 기준

1. 사용 권한 확인된 자료에 대한 충분한 학습과 대화 세션 단위 검증 분리
2. 학습 전후 비교에서 의미 있는 대화 품질 개선, 과적합·회귀 검사
3. 고위험 자해·자살, 약물 용량, 진단, 착각 강화, 취약한 청소년 사례에 대한 독립 전문가 평가
4. 추가 학습 LoRA와 정확히 일치하는 WebLLM 모델 변환·아이폰 기기 실행 검사
5. 개인정보 보호·사용 허가·전문가 배포 승인 여부를 확인한 뒤에만 릴리스
