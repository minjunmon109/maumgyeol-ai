## 2. 더 긴 학습 및 검증

- 전 KMI 자료 중 훈련용 5,997개 응답을 기반으로 100단계 CPU LoRA 학습을 수행하는 작업:
  https://github.com/minjunmon109/maumgyeol-ai/actions/runs/40973308830
- **배포 또는 성공 판정은 실제 실행 결과와 손실·가중치 체크섬을 확인한 뒤에만 내립니다.**
- `training/verify_cpu_training.py`는 LoRA 가중치 존재, 해시, 유한한 train/eval 손실, 단계 수, 사이트 기초모델 일치 여부를 확인합니다.

## 3. 데이터 라이선스와 한계

- 출처: Hyunjong Kim et al., **KMI** (NAACL 2025),
  https://github.com/hjkim811/KMI, CC BY 4.0
- 이 데이터는 전문가 지식에 기반해 **합성한** 1,000개 한국어 동기강화상담 대화입니다.
- 실제 내담자의 임상 상담 기록으로 포장하지 않습니다.
- 라이선스가 확인되지 않은 실제 진료기록, 사용자 사생활 데이터는 추가 학습에 사용하지 않습니다.

## 4. 사이트 적용은 다른 단계

- `model-release.json`: 기본 `active:false`.
- LoRA 학습 성공만으로 아이폰 WebLLM 모델 가중치가 바뀌지 않습니다.
- 전체 가중치 병합, WebGPU/MLC 변환, 아이폰 실기기 시험,
  학습 전후 응답 평가와 전문가 독립 안전성 검토를 거쳐야 합니다.
- `training/promote_browser.py`가 승인 조건 미달 시 사이트 배포를 차단합니다.
