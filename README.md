# 마음결 | Maumgyeol

마음결은 한국어 정서지원 대화 사이트 시제품이며, 전문 심리상담이나 진단·치료의 대체가 아닙니다.

## 기본 실행

- Python 서버: `ACCESS_CODE`와 `AUTH_SECRET`을 비공개 환경변수로 지정하고 `python app.py`로 실행
- 모바일/데스크톱: HTTPS 사이트에서 **기기 AI 시작 · 모델 다운로드**를 누르면 브라우저가 Qwen3 1.7B 4-bit 모델을 다운로드해 WebGPU로 직접 추론
- 일반 채팅, 음성 통화의 응답과 현실 대화 연습 모두 **하나의 Qwen3 1.7B 생성형 모델**을 사용. 규칙 기반 상담 답변 및 Kilo/OpenRouter 외부 AI API 호출 없음
- 사용량 제한: 외부 AI API의 일일 요청 할당량 없음. 다만 **GPU 메모리(모델 요구 약 2GB), 휴대전화 발열·배터리·저장 공간·성능**, 모델 파일 다운로드/CDN 가용성이 제한 요인
- iOS 26 Safari는 WebGPU를 지원하지만 아이폰 기종에 따라 메모리 부족으로 로딩 실패 가능. 실제 기기 테스트 필요
- 최초 다운로드 후 캐시가 유지될 수 있지만 브라우저에 의해 캐시가 삭제될 수 있고 완전한 오프라인 동작은 보장되지 않음
- 브라우저에서 모델을 실행하므로 채팅 추론은 서버로 보내지 않음. Firebase 계정 기능이 활성화돼 있으면 기록 저장/동기화는 별도이며 브라우저의 음성 인식 기능은 OS/브라우저 외부 서비스를 사용할 수 있음

실행을 위한 자세한 안내: [FREE_AI_SETUP.md](FREE_AI_SETUP.md).

개인 초대코드, API 키 및 서명키는 공개 GitHub 저장소에 저장하지 마세요.
