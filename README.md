# 마음결 | Maumgyeol

한국어 정서지원 대화 공간. 전문 상담·치료의 대체가 아닌 시제품입니다.

아이보리·딥그린 화면, 대화 집중 모드, 마음 기록과 호흡 기능을 제공합니다.
기본 AI는 API 키가 필요 없는 Ollama의 Qwen3 8B입니다. 모델 설치와 실행 환경은 [로컬 AI 안내](FREE_AI_SETUP.md)를 참고하세요.

시작: `ACCESS_CODE`와 `AUTH_SECRET` 환경 변수를 설정한 뒤 `python app.py`.
검증: `python -m unittest discover -s tests -v`.
