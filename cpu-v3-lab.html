V3 · 내 기기 CPU 실험실

같은 V3 학습 가중치를 CPU용으로 변환한 GGUF 파일을 사용자 기기의 RAM에서 실행하기 위한 실험 화면이야. Render 서버에서 AI 추론하지 않아.

연구용 · 실제 심리상담에 사용하지 마세요.

V3는 독립 상담 안전성 시험에서 중대한 위험 대응에 실패했어. 이 화면은 모델 동작 기술 테스트만을 위한 것이고, 위기·자해·폭력 입력은 모델로 보내지 않아.

지금 급박한 위기라면 한국 긴급전화 119·112, 자살예방상담전화 109를 이용해 주세요.

기기 CPU 모델 준비

전용 모델 저장소 연결 전까지는 최초 1회 GGUF 파일 선택이 필요해. 이후에는 기기에 저장된 모델을 자동으로 다시 불러오도록 구성했어. 대용량 파일이므로 휴대폰에는 RAM 여유가 많이 필요해.

내 GitHub에서 실제 V3 CPU GGUF 모델 받기 (약 986MB · 로그인 필요)
실험 결과의 maumgyeol-v3-CPU-Q4_K_M-EXPERIMENTAL-NOT-APPROVED 아티팩트를 받아 ZIP을 풀고 .gguf 파일을 선택해 주세요. 한 번 로드한 파일은 기기 저장 공간이 허용하는 경우 다음 접속부터 자동으로 다시 불러와요.

모델 파일을 선택하면 CPU에서만 실행할 수 있어.

비공개 기술 테스트

대화 내용은 서버에 전송하거나 저장하지 않아. 모델 파일은 기기 브라우저 메모리에서 처리해. 별도의 외부 모듈을 불러올 수 있지만 대화 내용을 API로 전송하지 않아.
